# نظام التصميم: «الإرشاد كخريطة طريق» (Wayfinding)

الإرشاد الأكاديمي في جوهره **دلالة طريق**: الطالب يبدأ من المستوى الأول ويمر بمحطات تحددها اللائحة (التدريب بعد 30 ساعة، مشروع التخرج بعد 94 ساعة) حتى يصل للتخرج عند 134 ساعة.
لذلك استعارت الواجهة لغة **لافتات الطرق وخرائط المترو**: لون أخضر اللافتات، خط المسار الأصفر، المحطات، وعلامة «أنت هنا».

## 1. الألوان

| الاسم | القيمة | الاستخدام |
|---|---|---|
| Sign green (`sign-600`) | `#0B6439` | الشريط العلوي، الأزرار الأساسية، الحالات السليمة (ناجح، معتمد) |
| Route yellow (`route-400`) | `#FFC72C` | خط التنقل، «أنت هنا»، المحطة الحالية، التمييز المهم فقط |
| Platform | `#EDEFEB` | خلفية الصفحات |
| Ink (`ink-900`) | `#191E1B` | النصوص؛ ودرجات `ink-50…950` للحدود والخلفيات المحايدة |
| Signal red (`signal-500`) | `#D33F2F` | الخطر الحرج، الرسوب، الأخطاء |
| Caution orange (`caution-500`) | `#E57E0B` | الإنذارات والتحذيرات |
| Lane blue (`lane-500`) | `#1F6FB2` | المعلومات، مسار الشبكات والأمن |
| Plum (`plum-500`) | `#7B3FA0` | مسار الذكاء الاصطناعي |

كل الألوان معرّفة في `src/index.css` داخل `@theme`، لذلك تعمل مباشرة كـ utilities مثل `bg-sign-600` و`text-signal-600`.
لا يُستخدم أي لون من ألوان Tailwind الافتراضية (indigo, slate, …).

**ربط الحالات بالألوان** موجود في ملف واحد `src/components/ui/tones.ts`:
مستوى الخطر، حالة الخطة، المسار، حالة التدريب، حالة المقرر، الأدوار، والتقديرات. أي صفحة تعرض حالة تستخدم نفس الملف، فتظهر الحالة بنفس اللون ونفس الاسم في كل مكان (وبالعربي أو الإنجليزي حسب اللغة).

## 2. الخط

عائلة واحدة: **Alexandria** (من تصميم مصري، تدعم العربية واللاتينية بأوزان 300–900).
الخط مُضمَّن في المشروع عبر `@fontsource-variable/alexandria` فيعمل **بدون إنترنت** (مفيد وقت المناقشة).

- عناوين الصفحات: 800، 28px
- عناوين الأقسام: 700، 16px
- النص: 400–500، 13–14px بتباعد أسطر 1.7
- أصغر حجم مسموح: 11px
- لا يوجد letter-spacing على النص العربي لأنه يكسر اتصال الحروف.

## 3. التخطيط والتنقل

```
┌──────────────── شريط أخضر ثابت (لافتة) ────────────────┐
│ [الشعار] المستشار الأكاديمي الذكي   [بحث Ctrl K] [EN] [🔔] [👤] │
│   ●━━━━━━━●━━━━━━━◉━━━━━━━●━━━━━━━●   ← خط المترو = القائمة الرئيسية │
└─────────────────────────────────────────────────────────┘
  عنوان الصفحة (أيقونة + عنوان كبير + جملة توضح الغرض + أزرار)
  أقسام بيضاء بحدود رفيعة
```

- **خط المترو** (`RouteNav`): كل صفحة «محطة»، والمحطة الحالية صفراء. يتغير حسب الدور.
- **البحث السريع** `Ctrl + K` (`CommandPalette`): الانتقال لأي صفحة أو تغيير اللغة أو فتح السجل الموثق أو تسجيل الخروج من لوحة المفاتيح.
- **الاتجاه**: كل المسافات والمحاذاة بخصائص منطقية (`ps/pe/ms/me/start/end`) فتعمل الواجهة صحيحة في العربية (RTL) والإنجليزية (LTR).

## 4. المكوّنات المشتركة (`src/components/ui`)

| المكوّن | الوظيفة |
|---|---|
| `PageHeader` | رأس كل صفحة: أيقونة، عنوان، وصف، أزرار |
| `Panel` / `PanelHeader` | قسم أبيض بعنوان |
| `Stat` | رقم واحد مع وصفه، ويمكن أن يعمل كفلتر قابل للضغط |
| `Chip` / `CodeBadge` | الحالات، وأكواد المقررات على شكل «لافتة خط» |
| `Segmented` | التبويبات والفلاتر |
| `Modal` | كل النوافذ المنبثقة: تُغلق بـ Esc أو بالضغط خارجها، وعند الطباعة تُطبع وحدها |
| `Toast` | رسالة تأكيد بعد أي إجراء |
| `Loader` | «قطار» يتحرك بين محطتين أثناء التحميل |
| `EmptyState` | حالة القوائم الفارغة مع الخطوة التالية |
| `JourneyRoute` | مسار الطالب من البداية للتخرج مع «أنت هنا» |
| `GpaScale` | المعدل على مقياس 0–4 مع حد الساعات المسموح لكل نطاق من اللائحة |

## 5. أسماء المؤسسة في المستندات الرسمية

اسم الجامعة والكلية الذي يظهر في السجل الموثق واستمارة التسجيل والخطة المطبوعة موجود في ملف واحد:
`src/config/institution.ts` — عدّله مرة واحدة وتتغير كل المستندات.

## 6. قواعد ثابتة

- كل نص ظاهر ثنائي اللغة عبر `t('عربي', 'English')`.
- لا تظهر قيم برمجية خام للمستخدم (مثل `HIGH` أو `Pending Review`).
- كل زر غير الإرسال عليه `type="button"`، وكل زر أيقونة فقط عليه `aria-label`.
- الحركة محدودة: رسم خط المسار مرة واحدة عند فتح لوحة الطالب وصفحة الدخول، وتُلغى تلقائياً لو المستخدم مفعّل «تقليل الحركة».
